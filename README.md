# Харків за день

План прогулянки з часом, відстанями й порадами - у [PLAN.md](PLAN.md).

Мобільний покроковий гід маршрутом: мінімалістична схема точок, що домальовується з кожним кроком, і картка з назвою, часом, описом та укриттям.

## Запуск

Відкрий `index.html` у браузері або підніми локальний сервер:

```
npx serve .
```

## Структура

- `data/spots.js` - усі точки маршруту (назва, час, координати, опис, укриття, як дістатися: `walk` / `taxi`). Редагуй тут.
- `app.js` - проєкція координат у SVG, анімація відрізків, кнопки «Назад» / «Далі», свайпи, збереження кроку.
- `scenes.js` - малювання ілюстрацій місць. Дев'ять сцен беруться зі спрайтів `data/places.js` (за реальними фото), Буфет намальований кодом. Індекс сцени = індекс точки в `spots.js`.
- `data/places.js`, `data/taxi.js`, `data/extra.js` - готові піксельні спрайти (RLE). Джерела фото - у [CREDITS.md](CREDITS.md).
- `style.css` - токени NES, стилі схеми й картки.

## Дизайн

- Шрифти: Oswald (заголовки, час), Montserrat (текст), Anonymous Pro (лейбли), Press Start 2P (лічильник кроків); усі з кирилицею.
- Палітра NES, лише темна тема: фон `#0c0e0c`, картка `#141519`, акцент і маршрут беж `#efc094`.
- Пішохідні відрізки - суцільна лінія, таксі - пунктир.
